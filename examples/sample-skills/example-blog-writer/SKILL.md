# example-blog-writer

A made-up skill that exists only to show what skill-dashboard-maker produces.

## Input
- Topic, 3 to 5 keywords, and optionally the audience and length

## Steps
1. Write 5 headline options that use the keywords.
2. Outline the post with 4 to 6 subheadings.
3. Write about 1,000 words, then add a short summary and hashtags.
4. Return Markdown (MD).

## Modes
- Informational post
- Review or personal-experience post
