# example-lesson-planner

A made-up skill that exists only to show what skill-dashboard-maker produces.

## Input
- Course topic, audience, total time (for example 3 hours, or 2 days of 8 hours)

## Steps
1. Set 3 learning objectives.
2. Build a curriculum table with the topic, activity, exercise and time for each session.
3. Write an opening, main part and wrap-up for each session.
4. Save the curriculum table and lesson plan as one DOCX.

## Modes
- Half-day workshop
- Multi-day course
